Configuration and Administration

This branch covers setup, inspection, runtime control, deployment, updates, backup, and rollback. It is the operator path rather than the ordinary playback path.

Start here

  1. config-interface.md — what the configuration console

controls.

  1. config-network-and-runtime.md — host,

port, SSH, path, and runtime verification.

  1. diagnostics-interface.md — endpoint calls,

queue inspection, and live previews.

  1. install-and-validation.md — installation and

clean-machine verification.

Administration branches

  • Feature configuration and persistence → config-feature-breakdown.md
  • Advanced JSON/runtime editing → config-advanced-json.md
  • Ratings database maintenance → config-ratings.md
  • Podcasts and filesystem paths → config-podcasts-and-library-paths.md
  • Display/render features → config-display-and-render-features.md
  • Alexa setup and reachability → config-alexa-setup.md
  • Notifications and scrobbling → config-notifications.md and config-lastfm-and-scrobbling.md

Runtime and deployment

  • Deployment, PM2/systemd, and verification → deployment-and-ops.md
  • Backend change verification → backend-change-verification-runbook.md
  • Live environment assumptions → local-environment.md
  • moOde upgrade recovery → the retained moOde upgrade runbook

Configuration changes can require different restart scopes. Always verify whether a change is browser-local, API-runtime, service, or moOde-host state before restarting anything.
